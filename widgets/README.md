# 把 MODI 机器人挂到桌面

## iPhone 主屏幕小组件（Scriptable）

小组件显示：机器人表情（盯盘 / 等信号 / 扫描 / 暂停 / 刚开仓 / 刚止损）、它正在做什么、OKX 模拟权益、今日盈亏，中号还显示浮盈最大的 3 个持仓。点小组件打开看板。

1. 在 App Store 安装免费 App **Scriptable**。
2. 用 Safari 打开 <https://raw.githubusercontent.com/modi-cjh/crypto-panel/master/widgets/modi-robot.js>，长按文字 → 全选 → 拷贝。
3. 打开 Scriptable → 右上角 **+** → 粘贴 → 点顶部标题改名为 **MODI 机器人** → 完成。可以先点右下角 ▶ 预览。
4. 回到主屏幕，长按空白处 → 左上角 **+** → 搜索 **Scriptable** → 选小号或中号 → 添加小组件。
5. 长按刚加的小组件 → **编辑小组件** → Script 选 **MODI 机器人**。

说明：
- 只读取公开的账户快照（GitHub `paper-data` 分支）和 OKX 模拟盘公开标记价，不需要也不会读取任何密钥。
- 能连上 OKX 时浮盈按模拟盘实时标记价计算（底部显示“实时浮盈”）；4G 下 OKX 被屏蔽时用快照数值（显示“快照数值”）。
- 刷新时机由 iOS 决定，通常 5–15 分钟一次；账户快照本身约每 40–50 分钟更新（GitHub 定时任务）。
- 脚本更新后需重新复制粘贴一次。

## 电脑桌面悬浮窗（Chrome / Edge）

在电脑上用 Chrome 或 Edge 打开看板 → 点机器人打开面板 → 底部 **桌面悬浮窗**。机器人会移到一个始终置顶的小窗里，可以拖到屏幕角落；小窗里显示权益、今日盈亏和它正在做什么，开 / 平仓时同样弹出票据，点它播报持仓。关闭小窗后机器人回到页面。Safari 和手机浏览器不支持这种悬浮窗，面板里不会显示这个按钮。
